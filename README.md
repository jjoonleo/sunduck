# sunduck

Small Python practice repository for CLI input parsing and object-oriented
programming.

## Contents

- `main.py` - interactive vault CLI
- `vault.py` - `Vault` class with private fields and methods
- `class.py` - class/property/static value examples
- `clac.py` - simple arithmetic expression parser for addition/subtraction

## Run

```bash
python3 main.py
```

or run an individual exercise:

```bash
python3 clac.py
```

## Portfolio Highlight

Use this as an archive of Python learning exercises, not as a featured project.
